CaYa Virtual Voice 1.0.1
==========================

Bu sürüm System.Speech.dll kullanmaz. Windows'un yerleşik SAPI 5 konuşma
bileşenini kullanır ve önceki "System.Speech.dll metadata bulunamadı"
hatasını giderir.

KULLANIM
1. ZIP dosyasını tamamen klasöre çıkar.
2. Baslat.bat dosyasını çalıştır.
3. Uygulamada sanal kablonun oynatma tarafını seç.
   VB-CABLE kullanıyorsan genellikle: CABLE Input
4. Discord/oyun/OBS mikrofon aygıtında kablonun kayıt tarafını seç.
   VB-CABLE kullanıyorsan genellikle: CABLE Output
5. Metni yaz ve Konuş düğmesine bas.

KISAYOLLAR
- Ctrl + Enter: Konuş
- Escape: Durdur

SORUN OLURSA
Baslat_HataAyiklama.bat dosyasını çalıştır ve görünen hatanın ekran
görüntüsünü paylaş.

GEREKSİNİMLER
- Windows 10 veya Windows 11
- Windows PowerShell 5.1 (Windows ile birlikte gelir)
- En az bir Windows konuşma sesi
